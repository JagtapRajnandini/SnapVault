Using a link () would be a security flaw — a malicious email containing would silently delete documents every time a logged-in user opened that email. POST requires the browser to make an intentional form submission, not a passive GET request. delete_form.hidden_tag() renders the hidden CSRF token: Flask-WTF validates this token in the delete route's validate_on_submit() call and rejects any request that does not carry a valid token. data-bs-toggle="modal" triggers Bootstrap's confirm dialog before the form is submitted — gives the user a chance to cancel before the irreversible action runs. #}
